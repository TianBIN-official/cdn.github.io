你从陌生的地方醒来，脑中无任何的记忆，也不知道自己是谁，来自什么地方。只知道自己身处陌生的环境中。
“同志，你醒了”一位青年的声音突然出现，把你吓了一跳，想一想也是，陌生的环境，肯定是有人的，只是还不知道为何自己会在这里。
“前几天，同志从天上掉进河里，我刚把同志拉上来了。”这句话让你的记忆恢复了一点，脑中有相关的记忆，所以这人说的没有错。
在你昏迷的这几天，都是由这位青年照顾你的，还有位小孩，青年照顾你，小孩劳动。这个世界不太了解，你身上的伤恢复了。
由于你忘记了自己身份信息，所以要去补办册籍，在补办之前，你与这位同志深度交流了一下，大概了解这世界的基础常识。
这位青年同志在你补办册籍失败之后，自愿在自己户口上写你的信息，你给自己取名，也有了户口，也算在这个世界站住了脚跟。这个世界的法律虽然严格，但很人性化，只要不作死，那就没事。
与这青年同志和小孩相处久了，也知道他们的名字，这青年名字“侯小宇”，小孩名字“苏泽”，他们的关系是兄弟关系。
